
🧠 Own RAG Application

About the Project

Own RAG Application is an AI-powered document question-answering system built using Retrieval Augmented Generation (RAG).

Users can upload PDF documents and ask questions. The application retrieves relevant information and generates answers using a Large Language Model.

Features

- Upload multiple PDF documents.
- Extract text from PDF files.
- Split documents into smaller chunks.
- Generate semantic embeddings.
- Retrieve relevant document sections.
- Generate AI-powered answers.
- Display retrieved context.

Technologies Used

- Python
- Streamlit
- PyPDF2
- Sentence Transformers
- Scikit-learn
- NumPy
- OpenRouter API

Project Structure

Own-RAG-Application/
├── app.py
├── requirements.txt
└── README.md

Installation

pip install -r requirements.txt

Run Application

streamlit run app.py

API Configuration

Enter your OpenRouter API key in the application sidebar.

Never upload API keys to GitHub.

Project Objective

To build a custom RAG application that combines document retrieval, semantic search and Large Language Models to provide context-based answers.
